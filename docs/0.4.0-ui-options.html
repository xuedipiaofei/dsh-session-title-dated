方案 B独立确认弹窗

Zilong 的做法：标题旁加自己的按钮，点开自己的“生成标题”弹窗，预览/重新生成/确认。

我的建议：先不做 0.4.0；真要做，优先方案 A，不做方案 B。
理由：0.3.0 的自动 + /retitle 已覆盖 90% 场景；
方案 A 只多一颗星，方案 B 多一套弹窗。
